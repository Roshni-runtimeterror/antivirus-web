🚀 About The Project

Antivirus Web is a modern frontend web application created to demonstrate how an antivirus/security platform can be presented through an intuitive web interface.

The project focuses on a clean cybersecurity dashboard where users can quickly understand their protection status, view security information, monitor scan activity, and interact with security-related features.

The interface is designed with a modern, responsive, and security-focused UI suitable for desktop and mobile screens.

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/Roshni-runtimeterror/antivirus-web.git

2. Navigate into the project

cd antivirus-web

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the application

After starting the development server, open the local URL shown in your terminal.
